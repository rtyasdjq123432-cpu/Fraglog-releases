# Fraglog

**Статистика CS2 в одной программе: FACEIT, Premier и Matchmaking.**

Fraglog — программа для Windows. Она сама собирает твои матчи и показывает, как ты играешь: рейтинг, K/D, ADR, HS%, винрейт по картам, разбор каждого матча и табло всех игроков.

## Скачать

**[Скачать последнюю версию](https://github.com/rtyasdjq123432-cpu/Fraglog-releases/releases/latest)** — файл `Fraglog-Setup-x.x.x.exe`.

Устанавливается один раз, дальше обновляется сама.

## Что умеет

- **FACEIT** — ELO, уровень, сколько осталось до следующего, дуэли и клатчи.
- **Premier, соревновательный, напарники, штурм** — все матчи из истории Steam, демки качаются и разбираются сами.
- **Разбор матча** — оценка игры, мультикиллы, бейджи, табло обеих команд, страница любого игрока.
- **Запись во время игры** — счёт виден прямо в программе, матч сохраняется сам.
- **Друзья** — сравнение статистики, матчи вместе и друг против друга.
- **Задания, достижения, уровни** — награды: цвета, рамки, живые фоны, титулы.
- **Свой фон** — картинка, GIF или видео.

## Установка

1. Скачай `Fraglog-Setup-x.x.x.exe` из [последнего релиза](https://github.com/rtyasdjq123432-cpu/Fraglog-releases/releases/latest).
2. Запусти. Если Windows покажет «Защитник Windows предотвратил запуск» — нажми **Подробнее → Выполнить в любом случае** (у программы нет платной подписи).
3. Войди через Steam. Пароль программа не видит — вход происходит на сайте Steam.

## Безопасность

- Все данные хранятся только на твоём компьютере.
- Программа не знает твой пароль Steam.
- Обновления скачиваются только отсюда, из этого репозитория.

## Требования

Windows 10 или 11, 64 бита.
